# Fury: Plataforma interna de desenvolvimento

Este repositório organiza a pesquisa desenvolvida para a execução do [trabalho](), incluindo as fontes e análises feitas pelos integrantes sobre o tema.

## O que é o Fury:

De maneira sintética, o Fury é a plataforma de desenvolvimento interna do Mercado Livre, desenvolvida para otimizar a gestão dos inúmeros serviços deste projeto ao mesmo passo que garante a autonomia de cada equipe sobre o seu domínio.

As principais funcionalidades da plataforma são:

* Automação de Pipelines;
* Abstração da Infraestrutura;
* Integração com IA;
* Gerenciamento de recursos massivos.
